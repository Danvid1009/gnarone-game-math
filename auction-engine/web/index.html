How this is fair. Each unit size has a fixed contents table with mean E[V]. Paying fee F and bidding B, you win when the rival's bid is below yours; the rival's fold chance is derived, G(B) = (0.95·(F+B) − B) / (E[V] − B), so every bid on every size returns exactly 95% of the outlay. Lose and the bid comes back; only the fee is spent. Bids are capped at E[V]/0.95 − F, above which no fold chance could return the RTP.
