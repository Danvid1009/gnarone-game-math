PICK ONE

An n-way bet with exact RTP. Options own zones of width pᵢ on the draw; backing option j pays RTP ÷ pⱼ on a hit, so every option returns exactly the RTP. Two equal options pay 1.9× at RTP 0.95; three pay 2.85×; five pay 4.75×. Weighted options work the same way.

Sample API (static fixtures)

One hundred pre-drawn rounds from fixed seeds (fixture-000 … fixture-099), one set per reference configuration (coin, five, weighted), served as plain JSON. The same seed drives every set, so round 007 uses the same u everywhere.

# what sets exist, their odds and files
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/index.json

# the configuration of one set: options / bands, probabilities, odds, RN intervals, how to settle
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/field.json

# one round (000–099): seed, u, outcome, settlement at stake 1000
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/rounds/007.json

# all 100 rounds of a set
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/rounds.json

# a worked RGS-shaped request/response pair (round 007)
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/sample-request.json
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/sample-response.json

Settlement rule is spelled out in each set's field.json under how_to_settle.

Demo balances are play credits. Draws use crypto.getRandomValues in the browser; the server-side engines use a seeded PRNG so every round replays from its seed.
