How this is fair. Option i owns a zone of width pᵢ on [0,1). A hit on option j pays RTP ÷ pⱼ, so E[win] = pⱼ × RTP ÷ pⱼ = RTP for every j. Two equal options pay 1.9× at RTP 0.95; five pay 4.75×.
LIVE API · HOW TO CALL

The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/pick-one/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/pick-one/api/rgs.js';

const g = createGame({ set: 'five' });                       // bet types: OPTION_1, OPTION_2, OPTION_3, OPTION_4, OPTION_5
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
const r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'OPTION_2' });   // fresh crypto seed; win in r.totalWinAmount
g.collect({ roundId: r.roundId });                                           // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'OPTION_2', seed: 'fixture-007' });
STATIC FIXTURES · 100 PRE-DRAWN ROUNDS

Seeds fixture-000 … fixture-099, served as plain JSON (GET, no auth, deterministic). Stake unit is 1000 minor units; scale linearly. The live module reproduces any of them when given the same seed.

curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/index.json                 # sets, odds, files
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/field.json            # configuration + odds
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/rounds/007.json       # one round (000–099)
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/rounds.json           # all 100 rounds
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/sample-request.json   # RGS-shaped request
curl -s https://danvid1009.github.io/gnarone-game-math/pick-one/api/coin/sample-response.json  # …and its response

Settlement rule: see how_to_settle in each set's field.json. Sets: coin, five, weighted — the same seed drives every set, so round 007 has the same u in all of them.
