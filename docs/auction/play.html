    WHAT'S INSIDE

    The locker pays value × X. X is a Single Shot draw with mean exactly 1, so opening never changes the expectation, only the spread.

    THE MATH

    Same ladder as the stepper: value after k bids ck = round(Mk/10, 2), survival Gk = 0.95 / ck. The first bid carries the whole 5% edge; every later bid is a fair bet (rivals fold with probability ck−1/ck). One uniform u places the outbid point; its residual inside that interval is recycled as the locker draw. Every take rule returns exactly 95%.

    LIVE API · HOW TO CALL

    The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/auction/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

    import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/auction/api/rgs.js';

const g = createGame();                                      // bet types: SMALL, MEDIUM, LARGE, XL
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
let r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'MEDIUM' });   // fresh crypto seed → nextAction ['CONTINUE']
r = g.nextAction({ roundId: r.roundId, actionCode: 'CONTINUE' });          // step: ['CONTINUE','CASH_OUT'] or the round ends
r = g.nextAction({ roundId: r.roundId, actionCode: 'CASH_OUT' });          // → totalWinAmount, nextAction ['COLLECT']
g.collect({ roundId: r.roundId });                                          // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'MEDIUM', seed: 'fixture-007' });
    STATIC FIXTURES · 100 PRE-DRAWN ROUNDS

    Seeds fixture-000 … fixture-099, served as plain JSON (GET, no auth, deterministic). Stake unit is 1000 minor units; scale linearly. The live module reproduces any of them when given the same seed.

    curl -s https://danvid1009.github.io/gnarone-game-math/auction/api/index.json                 # sets, odds, files
curl -s https://danvid1009.github.io/gnarone-game-math/auction/api/small/field.json            # configuration + odds
curl -s https://danvid1009.github.io/gnarone-game-math/auction/api/small/rounds/007.json       # one round (000–099)
curl -s https://danvid1009.github.io/gnarone-game-math/auction/api/small/rounds.json           # all 100 rounds
curl -s https://danvid1009.github.io/gnarone-game-math/auction/api/small/sample-request.json   # RGS-shaped request
curl -s https://danvid1009.github.io/gnarone-game-math/auction/api/small/sample-response.json  # …and its response

    Settlement rule: see how_to_settle in each set's field.json. Sets: small, medium, large, xl — the same seed drives every set, so round 007 has the same u in all of them.
