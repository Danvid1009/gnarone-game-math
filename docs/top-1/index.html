The same Elo race, one uniform recycled into the full ranking, with only the winner paid. Odds are RTP ÷ P(win) = RTP·W / wᵢ, so a 400-Elo gap is a 10:1 odds ratio and every racer returns exactly the RTP with no feasibility condition.

Live API (browser module)

The engine is published as an ES module that implements the RGS provider contract and rolls locally with crypto.getRandomValues: open, valid-bets, bet, collect, with the observed balance semantics (bet debits the stake, collect credits the win, integer minor units). No server, every round live, and any round replays from its seed. Bet types: Ace, Bolt, Cinder, Dash, Ember, Flint, Gale, Hex, Iris, Jolt, Kite, Lux.

import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/top-1/api/rgs.js';

const g = createGame({ mode: 'top1' });                      // bet types: Ace, Bolt, Cinder, Dash, Ember, Flint, Gale, Hex, Iris, Jolt, Kite, Lux
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
const r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'Bolt' });   // fresh crypto seed; win in r.totalWinAmount
g.collect({ roundId: r.roundId });                                           // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'Bolt', seed: 'fixture-007' });

Sample API (static fixtures)

One hundred pre-drawn rounds from fixed seeds, each resolved for every bet type, served as plain JSON. Deterministic, so two people calling the same round get the same answer.

# the field: racers, Elo, win/place/show probabilities, multipliers per racer
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/field.json

# one round (000–099): seed, u, full finishing order, podium, settlement for every racer at stake 1000
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/rounds/007.json

# all 100 rounds in one file
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/rounds.json

# a worked RGS-shaped request/response pair (round 007, backing Flint)
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/sample-request.json
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/sample-response.json

To settle a bet from a round: look up the backed racer in settlements; win = round(stake × multiplier) if its place is 1, 2 or 3, else 0. The order is also reproducible from the seed with the standalone function in the build block below.
