    PODIUM ZONES

      Zones—
      How this is fair. Strength is 10^(Elo/400), so pairwise odds are Elo's own formula. One uniform picks the winner from intervals sized by strength; the leftover part of that same number is stretched back to 0–1 and picks second, and so on (Plackett–Luce, exactly). Each racer's win, place and show probabilities are closed-form. Every place returns the stake plus a profit: first pays the full win profit P, second a quarter of it, third a fifth (the each-way convention), and P is solved per racer so every racer returns exactly the target RTP. A field where a favourite's top-3 chance reaches the RTP is rejected, because no positive profit could return it.
      LIVE API · HOW TO CALL

      The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/top-1/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

      import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/top-1/api/rgs.js';

const g = createGame({ mode: 'top1' });                      // bet types: Ace, Bolt, Cinder, Dash, Ember, Flint, Gale, Hex, Iris, Jolt, Kite, Lux
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
const r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'Bolt' });   // fresh crypto seed; win in r.totalWinAmount
g.collect({ roundId: r.roundId });                                           // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'Bolt', seed: 'fixture-007' });
      STATIC FIXTURES · 100 PRE-DRAWN ROUNDS

      Seeds fixture-000 … fixture-099, served as plain JSON (GET, no auth, deterministic). Stake unit is 1000 minor units; scale linearly. The live module reproduces any of them when given the same seed.

      curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/field.json            # configuration + odds
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/rounds/007.json       # one round (000–099)
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/rounds.json           # all 100 rounds
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/sample-request.json   # RGS-shaped request
curl -s https://danvid1009.github.io/gnarone-game-math/top-1/api/sample-response.json  # …and its response

      Settlement rule: look up the backed racer in settlements; win = round(stake × multiple) if its place is 1, 2 or 3, else 0.
