DECKS & PAYS

count → multiplier5→100 · 4→10 · 3→3 · 2→2 · 1→1
How this is fair. A pack is 5 cards without replacement from one of two decks. Per rarity it pays count × value × multiplier(count), and the expected pack win of each deck is an exact hypergeometric sum. Each bet type draws the low deck with the one probability that makes E[win] ÷ cost equal the target RTP. Bundles are 11 packs for the price of 10.
LIVE API · HOW TO CALL

The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/rip-rumble/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/rip-rumble/api/rgs.js';

const g = createGame();                                      // bet types: BASE, BOOSTED, BASE_BUNDLE, BOOSTED_BUNDLE
const s = g.open();                                    // session, balance 100000, chipLevels [1000,2000,5000,10000]
const r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'BOOSTED' });   // fresh crypto seed; win in r.totalWinAmount
g.collect({ roundId: r.roundId });                                           // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'BOOSTED', seed: 'fixture-007' });
