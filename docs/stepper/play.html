THE LADDER

    How this is fair. One random number is drawn when you bet and it fixes the pane that breaks. Left or right is your choice, but it doesn't change the outcome — both panes on a row share the same fate. Survival to rung k is exactly RTP ÷ payoutk, so every stopping rule returns 97.0%. Climbing higher changes the variance, never the expectation.
    LIVE API · HOW TO CALL

    The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/stepper/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

    import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/stepper/api/rgs.js';

const g = createGame();                                      // bet types: EASY, MEDIUM, HARD
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
let r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'MEDIUM' });   // fresh crypto seed → nextAction ['CONTINUE']
r = g.nextAction({ roundId: r.roundId, actionCode: 'CONTINUE' });          // step: ['CONTINUE','CASH_OUT'] or the round ends
r = g.nextAction({ roundId: r.roundId, actionCode: 'CASH_OUT' });          // → totalWinAmount, nextAction ['COLLECT']
g.collect({ roundId: r.roundId });                                          // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'MEDIUM', seed: 'fixture-007' });
