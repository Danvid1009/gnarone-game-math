THE MATH

Each tick: A lands with probability w / (1 + w), w = 10(powerA − powerB)/1200; damage is half-normal with mean 16 × w±¼, on a 0.5 HP grid. P(A wins | healths, tick) is computed exactly by backward induction from the end rule (health share at the bell). Opening odds = 0.95 ÷ P. Live odds = 1 ÷ P: a martingale, so no timing beats it.

LIVE API · HOW TO CALL

The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/fight/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/fight/api/rgs.js';

const g = createGame({ preset: 'even' });                    // presets: even, favourite, glass-cannon, slugfest
                                                       // bet types: A, B
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
let r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'B' });   // fresh crypto seed → nextAction ['CONTINUE']
r = g.nextAction({ roundId: r.roundId, actionCode: 'CONTINUE' });          // step: ['CONTINUE','CASH_OUT'] or the round ends
r = g.nextAction({ roundId: r.roundId, actionCode: 'CASH_OUT' });          // → totalWinAmount, nextAction ['COLLECT']
g.collect({ roundId: r.roundId });                                          // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'B', seed: 'fixture-007' });
STATIC FIXTURES · 100 PRE-DRAWN ROUNDS

Seeds fixture-000 … fixture-099, served as plain JSON (GET, no auth, deterministic). Stake unit is 1000 minor units; scale linearly. The live module reproduces any of them when given the same seed.

curl -s https://danvid1009.github.io/gnarone-game-math/fight/api/index.json                 # presets, parameters, bet types, realised RTP
curl -s https://danvid1009.github.io/gnarone-game-math/fight/api/even/field.json            # one preset: frozen config + tables + how to settle
curl -s https://danvid1009.github.io/gnarone-game-math/fight/api/even/rounds/007.json       # one round (000–099), settled for every bet type
curl -s https://danvid1009.github.io/gnarone-game-math/fight/api/even/rounds.json           # all 100 rounds (stake + win per bet type)
curl -s https://danvid1009.github.io/gnarone-game-math/fight/api/even/sample-request.json   # RGS-shaped request
curl -s https://danvid1009.github.io/gnarone-game-math/fight/api/even/sample-response.json  # …and its response

One folder per preset: even, favourite, glass-cannon, slugfest. Settlement rule is spelled out in each preset's field.json under how_to_settle; the same seed drives every preset, so round 007 has the same u in all of them.
