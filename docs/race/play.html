      How this is fair. Strength is 10^(Elo/400), so pairwise odds are Elo's own formula. The next finisher is drawn from those still running in proportion to strength (Plackett–Luce). Every ordered podium has a closed-form probability; sorted and laid end to end they tile 0–1, and one uniform draw picks one. Odds are set so every racer returns exactly the target RTP: the favourite and the outsider are the same bet, at different variance.
