    How this is fair. One uniform number is drawn when you bet and projected to 0–10000. Zone widths are the probabilities, so the chance of each payout is exactly its width. Inside a zone the payout rises in a straight line from a − r to a + r, so each zone's mean is exactly a and the total return is exactly Σ pᵢaᵢ. r is one tenth of the smallest gap between payouts, so zones never overlap and nothing ever pays between 0 and the lowest prize.
    SAMPLE API · HOW TO CALL

    Static fixtures: 100 pre-drawn rounds from seeds fixture-000 … fixture-099, served as plain JSON (GET, no auth, deterministic). Stake unit is 1000 minor units; scale linearly.

    curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/index.json                 # sets, odds, files
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/field.json            # configuration + odds
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/rounds/007.json       # one round (000–099)
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/rounds.json           # all 100 rounds
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/sample-request.json   # RGS-shaped request
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/sample-response.json  # …and its response

    Settlement rule: see how_to_settle in each set's field.json. Sets: maxent, geometric, weights — the same seed drives every set, so round 007 has the same u in all of them. Full write-up: Single Shot page.
