SINGLE SHOT

A single-shot payout function. The field is the 0–10000 draw; zone widths are the probabilities; inside a zone the payout ramps from a − r to a + r. Payouts and RTP in, a monotone payout(u) out, exact by summation.

Sample API (static fixtures)

One hundred pre-drawn rounds from fixed seeds (fixture-000 … fixture-099), one set per reference configuration (maxent, geometric, weights), served as plain JSON. The same seed drives every set, so round 007 uses the same u everywhere.

# what sets exist, their odds and files
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/index.json

# the configuration of one set: options / bands, probabilities, odds, RN intervals, how to settle
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/field.json

# one round (000–099): seed, u, outcome, settlement at stake 1000
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/rounds/007.json

# all 100 rounds of a set
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/rounds.json

# a worked RGS-shaped request/response pair (round 007)
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/sample-request.json
curl -s https://danvid1009.github.io/gnarone-game-math/single-shot/api/maxent/sample-response.json

Settlement rule is spelled out in each set's field.json under how_to_settle.

cd gnarone-game-math/payout-engine
npm test
node bin/build-payout.js --payouts 0,0.5,1,2,5,20 --rtp 0.95 --js

Demo balances are play credits. Draws use crypto.getRandomValues in the browser; the server-side engines use a seeded PRNG so every round replays from its seed.
