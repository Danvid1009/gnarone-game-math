How this is fair. The number of rocks crushed is drawn from a fixed table; on 2 or 3 a gem fires with a fixed chance and its multiplier comes from a weighted table. Return is the exact sum over the 16 outcomes: 97.07% base, 97.15% boosted. Boosted stakes are two chips, so its multiples of stake are the sheet's wins ÷ 2.
LIVE API · HOW TO CALL

The engine ships as a browser module at https://danvid1009.github.io/gnarone-game-math/game-of-three/api/rgs.js. It speaks the RGS provider contract (open, valid-bets, bet, next-action, collect; money in integer minor units; bet debits, collect credits) and rolls with crypto.getRandomValues in your page, so there is no server and every round is live. Pass seed to replay a round.

import { createGame } from 'https://danvid1009.github.io/gnarone-game-math/game-of-three/api/rgs.js';

const g = createGame();                                      // bet types: BASE, BOOSTED
const s = g.open();                                    // session, balance 100000, chipLevels [100,200,500,1000,2500,5000,10000]
const r = g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'BOOSTED' });   // fresh crypto seed; win in r.totalWinAmount
g.collect({ roundId: r.roundId });                                           // credits the win → { balance }

// Replay any fixture: same seed, same code path, same answer as rounds/007.json
g.bet({ sessionId: s.sessionId, betAmount: 1000, betType: 'BOOSTED', seed: 'fixture-007' });
