    PODIUM ZONES

      Zones—
      How this is fair. Strength is 10^(Elo/400), so pairwise odds are Elo's own formula. One uniform picks the winner from intervals sized by strength; the leftover part of that same number is stretched back to 0–1 and picks second, and so on (Plackett–Luce, exactly). Each racer's win, place and show probabilities are closed-form; third pays a fixed M₃, second sits θ of the way from third to first, and first is solved so every racer returns exactly the target RTP. A field where a favourite's top-3 chance reaches RTP/M₃ is rejected, because then winning could not pay more than third.
