Step-band payout: 10,000 rounds

Each round draws u uniformly on [0,1), reads the step function A(u) (one constant payout level per draw region), then adds a fixed neighbourhood ±r with r = 0.1 × the smallest gap between adjacent non-zero levels. The zero region pays exactly 0 and the lowest band sits strictly above zero. Every orange dot is one simulated round at a 100-cent stake, plotted at its draw.

With a payout standard deviation of 0.90× the stake, one standard error over 10,000 rounds is 0.9 points, so this run is inside normal sampling noise. The step function's RTP is Σ Δu·level = 0.97 by construction; the run only checks that the sampler agrees.
